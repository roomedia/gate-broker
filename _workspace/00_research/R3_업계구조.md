# R3: 업계/직업 구조 — 재난관리·군·심사기관·협회형 조직

**신뢰도**: HIGH
**근거**: 교차검증 2개+ 출처 항목 다수 (Tier 1: law.go.kr 법령·국가법령정보, 국민체육진흥법 개정안 2건 / Tier 2: 연합뉴스·SBS·노컷뉴스·문화일보·세계일보·한경매거진·나라경제 보도 / Tier 3: 전문 정리 블로그), 미확인 항목 3건 (<10%)
**목적**: 『게이트 브로커로 회귀했다』 속 헌터 협회·심사관·게이트 관리 조직의 계층/권한/커리어 패스 설계를 위한 현실 레퍼런스

## 1. 현실 재난관리 조직의 체계

### 1-1. 재난및안전관리 기본법 지휘계통
- **중앙**: 국무총리(위원장) 소속 **중앙안전관리위원회**가 중요정책 심의·총괄조정. 중앙사고수습본부는 주무부처, **중앙재난안전대책본부(중대본)**는 행정안전부에 설치 (출처: 위키백과 '재난 및 안전관리 기본법' 조문 요약 / 검색: 재난및안전관리 기본법 제14조)
- **지역**: 시·도지사/시장·군수·구청장이 본부장인 **지역재난안전대책본부**. 시·군·구 본부장은 재난현장 통합지원본부(통합지원본부) 설치·운영 가능, 통합지원본부장은 부단체장 (출처: 법령 전문 게재 http://hygs.co.kr/board/bbs/board.php?bo_table=notice&wr_id=21 — 제16조 전문)
- **현장**: **긴급구조통제단** — 소방서(긴급구조기관: 소방청·소방본부·소방서 / 해상은 해경). 대응 단계 격상 시 긴급구조통제단이 발동, 현장지휘소는 지휘텐트+지휘차 조합 (출처: https://fire1423.tistory.com/31)
- **지휘 원칙**: 수습본부장은 재난 수습에 필요한 범위에서 시·도지사/시장·군수·구청장을 **지휘**할 수 있음 (제15조⑥). 통합지원본부장은 긴급구조에 대해서는 시·군·구 긴급구조통제단장의 **현장지휘에 협력** (제16조③) — 즉, 현장 실무 지휘권과 행정 지휘권이 분리되어 있음
- **등급별 대응**: 소방 대응 1단계(일상 사고, 인근 3~7개 소방서, 현장지휘대장 권한 발령) → 2단계(광역 지원, 유관기관 협조 강화) → 3단계로 격상. 격상할수록 동원 인원·장비·관할 본부 권한 확대 (출처: https://fire1423.tistory.com/31)

### 1-2. 현장 지휘관의 권한과 검증 체계
- 소방청 표준절차 구호 **'지상전투'**: "지휘권 선언 → 상황 평가 → 전략·전술 → 투입 결정". 지휘권 선언이 제1절차 = 현장지휘관의 권한 선언 자체가 SOP의 시작 (출처: https://www.munhwa.com/article/11616894, https://www.mt.co.kr/policy/2026/09/14/2026091410034128166)
- **지휘역량 인증교육**: 소방경 이상 지휘관 대상 전국 10개 지휘역량강화센터(ICTC) 단계 교육, 소방정 승진자는 6개월(24주) 정책관리자과정 이수 후 보직 부여. 소방준감 후보자는 역량평가(조직관리·전략기획·의사소통·협업) 도입 예정 (출처: 위 2건)
- 조직문화 쇄신: 감찰 기능 + 익명 제보·제보자 보호체계 강화, 갑질·비위 엄정 대응 (출처: https://www.mt.co.kr/policy/2026/09/14/2026091410034128166)

> **픽션 적용 포인트**: (1) 게이트 발생 시 '등급별 대응 단계' 격상 메커니즘 차용, (2) 현장지휘권 선언이 공식 절차의 1단계라는 점 → 심사관이 현장에 대한 법적 권한을 행사하는 장면의 현실감, (3) "지휘관의 판단 하나가 성패와 대원 안전을 좌우"한다는 인식 → 심사관 개인 권한의 서사적 무게

## 2. 소방 계급·승진·인사 체계

**10단계 계급** (소방사→소방총감):
| 계급 | 대응 군/경찰 계급 | 역할 |
|---|---|---|
| 소방사 | 순경/하사 | 현장 실무 (화재진압·구조·구급) |
| 소방교 | 경장/중사 | 현장 실무 |
| 소방장 | 경사/상사 | 팀 중간관리자, 후배 교육 |
| 소방위 | 경위/소위 | 지구대장·상황실 등 책임자 (간부 시작) |
| 소방경 | 경감/중위 | 중간관리자 |
| 소방령 | 경정/소령 | 소방서장·본부 실과장 (관리직) |
| 소방정 | 총경/대령 | 소방서장·본부 과장급 |
| 소방준감 | 경무관/준장 | 본부 과장·소방학교장 (계급정년 6년) |
| 소방감 | 치안감/소장 | 소방청 차장·시도 본부장 (계급정년 4년) |
| 소방총감 | 치안총감/대장 | 소방청장 (1인) |

(출처: https://skyufo.tistory.com/entry/🚒-소방관-계급-구조부터-진급-월급까지-한눈에-정리 / https://sportscom.co.kr/소방관-계급-한눈에-11개-직급의-역할과-승진-기간은 / 교차검증 2건)

**승진 경로**:
- 소방사→소방교 1~2년, 소방교→소방장 3~4년, 소방장→소방위 4~5년 평균
- **최저근무연수**: 소방사→교 1년, 교→장 1년, 장→위 2년, 위→경 2년, 경→령 3년, 령→정 3년, 정→준감 4년
- **근속승진**(자동): 소방사 4년→소방교, 소방교 5년→소방장, 소방장 6년6개월→소방위, 소방위 8년→소방경
- **소방위까지 승진시험**, 그 이상은 승진심사·인사추천제 (출처: 위 2건 + https://adipo.tistory.com — 소방공무원법: 소방령 이상은 소방청장 제청→국무총리→대통령 임용)
- **계급정년**: 소방정 11년·소방령 14년·소방준감 6년·소방감 4년 → 승진 실패 시 명예퇴직 압박 (출처: https://adipo.tistory.com)

> **픽션 적용 포인트**: (1) "심사관도 계급정년이 있다" = 부패 심사관의 절박한 동기 (진급 실패→퇴직 공포), (2) 하위 계급은 근속·시험으로 오르지만 상위 계급은 **심사·추천제** = 파벌·연줄이 끼어들 여지 (비리 취약점의 현실 모델)

## 3. 군 장교 계급·보직·진급 심사 (심사관 권한의 현실 모델)

**군인사법 제26조 계급별 최저 복무기간**: 소위 1년 → 중위 2년 → 대위 6년 → 소령 5년 → 중령 4년 → 대령 3년 (준장 이상은 별도)
- 소위→중위: **근속 진급** (1년, 별도 심사 없이 자동)
- 중위→대위: 2~3년, 평가·심사 포함
- 대위→소령: 최저 6년이지만 실제로는 **임관 후 11년** 결합조건 → 11년 차에 소령 진급. 장기복무 선발과 맞물린 최대 병목 (출처: https://auddks.tistory.com/2652 / https://ccgv.tistory.com — 2건 교차)
- 대령→준장: 임관 25~26년 차 최단, 보통 27~29년 차. 장군 진급은 '하늘의 별 따기'
- **근속 승진 제도**: 심사에서 계속 탈락해도 일정 기간 성실 복무 시 자동 진급 (대위→소령 11년 이상 근속 등) — "장기 복무자의 직업 안정성 보장" 목적
- 진급의 실제 변수: **필수 보직(중대장 등) 이수 여부 + OAC(고등군사반) 교육 성적** — 연차가 아니라 **보직 이력**이 관문 (출처: https://ccgv.tistory.com)

> **픽션 적용 포인트**: (1) 헌터 심사관도 "연차만으로 못 오르는 계급" 설계 → 주인공 서도준의 빠른 승진이 파벌의 표적이 되는 구조, (2) 필수 보직(위험 게이트 현장지휘 등) 이수 여부가 진급 관문 → 길드가 보직 배정을 조작해 경쟁자를 탈락시키는 플롯, (3) 근속승진 = 실력 없이도 살아남는 관료 심사관의 온상 (1단계 빌런의 현실성)

## 4. 자격 심사·인증 기관의 구조

### 4-1. 인증심사원 자격취소·정지 기준 (친환경농어업법 시행규칙 별표 9의2 — 심사관 제재의 실제 모델)
- **부정한 방법으로 심사원 자격을 취득**한 경우: 2회 위반 시 **자격취소**
- **부정한 방법으로 인증심사 업무 수행**: 2회 위반 시 **자격취소**
- 고의·중과실로 기준 미달 인증: 2회 위반 시 **자격취소** / 경미한 과실: 시정조치→정지 3개월→정지 6개월
- **명칭 대여(자격증 빌려줌)**: 1회 정지 3개월 → 2회 정지 6개월 → 3회 취소
- 교육 미이수: 시정조치→정지 3개월→정지 6개월 (출처: https://www.law.go.kr/LSW/flDownload.do?flSeq=151417317 — Tier 1)

> 핵심 구조: **위반 횟수 누진제** + 고의/중과실/경과실 **3단계 과실 등급** + 최근 3년 내 반복 시 가중. 이 구조 그대로 헌터 심사관 징계 규정 설계 가능

### 4-2. 심사관 윤리 규정의 국제 표준 (ACFE 공인부정조사사 CFE)
- 자격 요건: 학사+2년 실무 경력, 40점 이상 자격 점수, 추천서(인성 증명), 400문항 시험(4개 섹션, 60일 내)
- 윤리 강령: 불법·비윤리·이해충돌 활동 금지, 최고 수준 청렴성, 합리적 기대 범위 내 업무만 수락, **기밀 정보 누설 금지**, 발견된 중요 사항 공개 의무 (출처: https://ko.wikipedia.org/wiki/공인부정조사사)
- 윤리 위반 시: 자격 박탈, 시험 응시권 상실·무효, 비용 미환급 (출처: http://astqb.org/about/astqb-ethics-complaint-process/)

### 4-3. 공직경력 특례의 폐지 움직임 (심사 제도의 공정성 논쟁)
- 법무사·세무사·변리사 등 **국가전문자격 15종**의 공직경력 특례(시험 면제·자격 자동 부여) 폐지 추진 중 (국민권익위, 10개 부처 권고)
- 2021년 세무사 2차 시험: 공무원만 면제받은 과목 **과락률 82.1%** → "공직 사회 스스로 공정 문화 정착 저해" 비판 (출처: https://news.sbs.co.kr/news/endPagePrintPopup.do?news_id=N1007707968)

> **픽션 적용 포인트**: (1) 심사원 징계 누진제는 그대로 헌터 심사관 '징계 포인트제'로 차용, (2) "전직 길드원이 협회 심사관으로 낙하산 특례 입직" 논쟁 = 헌터 협회 내부 공정성 갈등의 현실 밀착 소재, (3) 명칭 대여 처벌 = 심사관이 자격증을 브로커에게 빌려주는 비리 패턴의 현실 근거 (R6 연계)

## 5. 협회형 조직의 권력 구조와 파벌 패턴 (대한체육회 사례)

- **이중적 지위**: 정부 재정을 지원받으면서도 자율성을 내세우고, 동시에 국가올림픽위원회(NOC) 역할 수행 → "선거가 형식적 합리성을 띠는 동시에 실질적 책임성을 결여" (출처: https://sports.news.nate.com/view/20251004n06699)
- **간선제**: 회장 선거가 제한된 선거인단 간접투표 → 소수 대의원이 권력 좌우. 2025년 제42대 회장 선거: 선거인 1209명 중 유승민 417표, 38표 차 당선 (출처: https://seo.goover.ai/report/202501/go-public-report-ko-16498291-7b46-45ae-b9c7-1c53763232d0-0-0.html)
- **장기집권 메커니즘**: 이기흥 전 회장, 체육회 임원 **연임 제한 폐지** 의혹 → 권력 집중. 정부합동점검: 직원 부정 채용(자녀 대학 친구), 자격 요건 완화 지시, 반대 부서장 교체, 물품 사적 사용 의혹 → 문체부 직무정지·경찰 수사 → 2026년 9월 **증거 불충분으로 불송치** (출처: https://www.yna.co.kr/view/AKR20260919050651004, https://www.hankookilbo.com/news/article/A2026092109340000151)
- **개혁의 한계**: 인물이 바뀌어도 제도(간선제)는 유지 → "바뀐 것은 인물이지 제도는 아니다". 국민체육진흥법 개정안(2026.7.13 발의): 경기단체 회장은 회원 전원 직접선거로 → 문체부 승인 유지 (출처: https://assets.uhheung.kr/bills/pdfs/019f627c-5e14-749e-b2c1-c15387f9d17b.pdf)
- 국제 유사 패턴: FIFA·IOC도 형식적 민주주의 절차 + 부패·기득권 재생산 비판 반복 (출처: https://sports.news.nate.com/view/20251004n06699)

> **픽션 적용 포인트**: (1) 헌터 협회 회장은 '정부 승인'이 필요한 선출직 + 간선제 = 정권·대형 길드가 회장을 좌우하는 구조, (2) 연임 제한 폐지로 장기집권 → 3단계 이전의 상층 파벌 빌런 모델, (3) 내부고발의 64%가 불문 종결 → 고발해도 묻히는 현실 = 주인공이 제도 안에서만 싸울 수 없는 이유 (내적 갈등과 연결)

## 7. 실무 프로세스 3종

### (1) 게이트 대응 표준절차 (소방 '지상전투' 차용)
**게이트 탐지 → 등급 판정(심사관) → 대응 단계 격상 선언 → 지휘권 선언 → 현장 평가 → 전략 수립 → 길드 투입 배정 → 사후 검증(심사관)**
- 각 단계에 심사관의 서명·승인이 필요 → 권한의 실무적 무게

### (2) 헌터 등급 승급 심사 프로세스
**서류 심사(공적 기록) → 실기 검증(심사관 입회) → 심사위원회 평정(다수결) → 이의신청(30일) → 최종 등록**
- 이의신청 창구가 파벌의 개입 지점 (평정표 점수 조작은 실제 선관위 채용비리 사례 패턴 — R6 참조)

### (3) 심사관 징계 프로세스 (인증심사원 모델)
**제보 접수 → 예비 조사 → 본조사(징계위원회) → 과실 등급 판정(고의/중과실/경과실) → 누진 제재(시정→정지 3개월→정지 6개월→자격취소) → 재심 청구**
- 최근 3년 내 반복 시 가중, 중징계는 해임·자격취소

### 8-2. 심사관 직급 체계 (10단계, 소방 차용)

| 직급 | 현실 대응 | 권한 |
|---|---|---|
| 심사관보 (시보) | 소방사 시보 | 현장 참관만, 단독 심사 불가 |
| 3급 심사관 | 소방사·교 | 하위 게이트 등급 판정, 서류 심사 |
| 2급 심사관 | 소방장 | 중위 게이트 등급 판정, 실기 검증 입회 |
| 1급 심사관 | 소방위 | 승급 심사 서명권 (간부 시작) |
| 수석 심사관 | 소방경 | 심사위원장 자격, 대형 게이트 대응 단계 격상 발의 |
| 심사국장 | 소방령 | 국 단위 심사 총괄, 심사관 보직 배정 권한 |
| 본부장 | 소방정 | 본부 지휘, 길드 투입 배정 승인 |
| 이사 | 소방준감 | 이사회 의결, **직급정년 6년** |
| 부회장 | 소방감 | 협회장 대행, **직급정년 4년** |

- **승진**: 1급까지는 근속+시험, 수석 이상은 심사·추천제(파벌 정치의 장)
- **직급정년**: 수석 14년·국장 11년·이사 6년·부회장 4년 [미확인: 수치는 소방 계급정년 차용 — 픽션 설정값이므로 작가가 조정 가능]
- **필수 보직**: 수석 승진에는 '대형 게이트 현장지휘' 이력 필수 → 길드가 보직 배정을 장악하면 경쟁자를 탈락시킬 수 있음

### 8-3. 심사관의 권한 (현실 모델에서 도출)

1. **등급 판정권**: 게이트 발생 시 등급 판정 서명 → 대응 단계·투입 길드 규모 결정 (소방 대응 단계 격상 모델)
2. **지휘권 선언**: 현장에서 심사관이 '선임 심사관' 선언 시 해당 게이트의 최고 의사결정권 (소방 '지휘권 선언' 차용)
3. **승급 심사권**: 헌터 승급 평정 서명 — 길드의 핵심 인력이 심사관 손에 달림
4. **유통 허가권**: 마석 유통·게이트 부산물 거래 허가 (심사관이 이권의 문지기)
5. **징계 발의권**: 부정 헌터·길드에 대한 징계조사 발의 (인증심사원 모델)

### 8-4. 승진 경로 (주인공 서도준의 로드맵)

```
심사관보 → 3급 (2년) → 2급 (4년) → 1급 (심사 통과) → 수석 (필수보직 이수+추천) → 국장 → 본부장
    ↑ 위장 취업 진입점                    ↑ 회귀 지식으로 최단 돌파 구간        ↑ 파벌의 전면 견제 시작
```

- 서도준은 '1급→수석' 구간을 전생 지식(대형 게이트 예측 성공)으로 파격 돌파 → 기존 파벌의 질서 교란 → 2단계 갈등(대형 길드·협회 파벌 견제)의 구조적 원인

### 8-5. 비리 취약점 (서사 소재 — R6과 연계)

| 취약점 | 현실 근거 | 픽션 활용 |

## 부록: R4 스킵 사유

**R4 스킵 사유: 헌터물 판타지 세계관 특성상 현실 사건 연표 적용 불가, 핵심 역량(미래 지식) 연표는 부트스트랩 단계에서 픽션 내 게이트 사건 연표로 대체 설계**
- 본작은 10년 전 회귀를 전제로 하며, 주인공의 핵심 자산은 '미래 게이트 발생 예측'임. 현실 역사 연표는 세계관과 무관하므로 R4는 수행하지 않음. 대신 부트스트랩 단계에서 (1) 회귀 전 10년간의 주요 게이트 사건(붕괴·대형 공략·길드 흥망) 픽션 연표, (2) 주인공이 아는 '미래 지식' 타임라인을 별도 설계할 것.

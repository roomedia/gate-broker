# R6: 갈등 사례 — 재난·심사 분야 실제 비리/갈등 패턴

**신뢰도**: MEDIUM
**근거**: 교차검증 1개+ 출처 (Tier 2: 연합뉴스·한국일보·세계일보·SBS·노컷뉴스·뉴스1·아시아경제·더팩트·경북도민일보·미디어제주·전북도민일보·서울시 안전감사 사례집 7건 + Tier 1: 국민체육진흥법 개정안, AI부정행위 제도개선 공지), 각 사례는 단일 보도 출처이나 서로 다른 매체의 다수 사례가 동일 패턴을 뒷받침. 미확인 항목 2건 (<10%)
**목적**: 『게이트 브로커로 회귀했다』의 빌런(부패 심사관·대형 길드·협회 파벌) 모티프가 될 실제 갈등/비리 패턴 수집

## ★ 윤리 원칙 준수 선언

본 보고서는 과제에서 부여된 엄격한 제약을 준수한다:
- **실존 대형 참사(세월호·이태원·삼풍 등)의 희생자·유가족을 서사 소모품으로 다루지 않는다.** 해당 참사는 사례 수집 대상에서 제외했으며, 보고서 어디에도 참사 자체의 재현·묘사를 포함하지 않는다.
- 수집 대상은 **'구조적 비리/이권 메커니즘' 패턴**(입찰 비리, 점검 조작, 기금 착복, 심사 비리, 내부고발 탄압)에 한정한다.
- 특정 실존 인물의 실명을 빌런의 직접 모델로 지목하지 않으며, 사건은 '패턴 추출용'으로만 기술한다.

**준수 여부: 준수함.** 이하 모든 사례는 제도·절차·이해관계의 구조적 결함만을 추출한다.

## 1. 재난·안전 분야 이권 다툼/비리 사례

### 사례 1. 국립소방병원 입찰 비리 — 내부문건 유출 + 심사위원 포섭
- **이해관계**: 발주기관 내부자(소방청 기획조정관·소방위) ↔ 심사위원(대학교수) ↔ 입찰 참가 건축사무소
- **수법**: 내부 입찰 문건을 브로커에게 유출 → 사전에 심사위원을 포섭 → 특정 업체에 유리한 점수 배점 → 입찰 방해
- **결과**: 이흥교 전 소방청장 징역 2년 6개월 구형, 소방위 징역 3년 구형, 교수 2명 각 징역 1년 구형, 건축사무소 대표 등 4명 징역 8월~2년 구형 (2026년 9월 결심공판, 청주지법)
- **구조적 포인트**: 점수제 심사의 **배점 재량**이 곧 이권. 심사위원 명단 사전 확보 → 포섭 → "합법적"인 점수로 특정 업체 낙찰
- 출처: https://mcj.nocutnews.co.kr/news/6582968 (검색: 소방 안전관리 입찰 비리)

### 사례 2. 산불 복구 유령업체 부정입찰 — 실적 조작 + 자격증 대여
- **이해관계**: 산림사업 사주 ↔ 유령업체 41개 ↔ 국세청/발주기관
- **수법**:
  - 입찰 실적 요건 충족을 위해 유령업체 간 **거짓 세금계산서 수수**(약 300회 입찰 중 20회 낙찰)
  - 지역제한 입찰 규정 회피 위해 5년간 **사업장 16차례 이전**
  - 낙찰자(유령업체)와 실제 용역 제공자(실사업자) 분리 → 사실과 다른 세금계산서
  - 산림사업 필수 기술인력 미채용 → **자격증 대여료만 급여로 우회 지급**
  - 배우자 등 명의상 대표자에게 급여 형태로 법인자금 약 10억 유출
- **결과**: 국세청, 10개 업체(유령 41개) 세무조사 착수. 탈루 혐의 약 700억원. 6500회 입찰 참여 → 260여회 약 230억원 낙찰. 이재명 대통령 "구조적 부정비리 제재" 지시 (2026년 5월)
- **구조적 포인트**: "영세하다는 이유로 세무 검증의 사각지대" — 공공입찰 참여기업의 검증 공백이 구조적 허점
- 출처: https://www.asiae.co.kr/article/2026090311173461864 (검색: 산불 복구업체 부정입찰)

### 사례 3. 경북 재해복구 공사 대금 체불 — 말단 착취 구조

- **수법**: 900일 대규모 수해 복구 공사에서 유류비·자재대·장비임대료 **1억 4160만원 미지급**. 시공사는 "자금난" 핑계, 부담은 개인사업자·영세 상인에게 전가
- **구조적 포인트**: 공공공사 하도급 대금 지급 확인 시스템이 갖춰져 있음에도 현장 말단까지 돈이 안 흐르는 **'돈맥경화'**. "도에서 발주한 공사라 믿고 납품했는데" — 공공의 신뢰가 영세 업체의 리스크가 됨
- 출처: https://m.tf.co.kr/amp/ogmeta/2303232.htm (검색: 재해복구 공사 체불)

### 사례 4. 제주 재난관리기금 착복 — 허위공문서 + 비자금
- **이해관계**: 서귀포시·제주시 공무원 ↔ 건설업자 ↔ 마을이장
- **수법**:
  - 마을 주민이 하천지장물 제거작업을 한 것처럼 **허위 기재** → 4개 마을에 재난관리기금 4887만원 불법 지원
  - 회계연도 경과로 기금 사용 불가 → 작업을 2007년 12월 시행한 것처럼 **허위공문서 작성·행사**
  - 기초 회계절차 없이 11곳 하천 사업 발주 → 연고 업체 7곳에 장비임차비 부풀려 지급(8748만원 과다 지출) → 대가로 뇌물 100만원·50만원 수수
  - 재난기금 1296만원 인출 → 43만원짜리 등산자켓 30점 구입해 직원들에 나눠줌
  - 재해복구비 과다지급 후 되돌려받아 **비자금 946만원** 조성 → 유흥비·선물비로 사용
- **결과**: 공무원 16명·건설업자 12명 등 총 28명 검거, 착복 총액 약 3억 4591만원

- 출처: https://www.mediajeju.com/news/articleView.html?idxno=62517 (검색: 재난관리기금 착복 공무원)

### 사례 5. 소방시설관리사증 6년 대여 — 자격의 임대 시장

- **구조적 포인트**: 자격증이 '실력 증명'이 아니라 **'업체 등록 요건 충족용 임대 자산'**으로 기능. 시스템상 기록(배치시스템)과 실체(현장)가 분리된 틈새
- 출처: https://www.news1.kr/local/busan-gyeongnam/6280796 (검색: 소방시설관리사증 대여)

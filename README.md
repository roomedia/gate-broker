# 게이트 브로커로 회귀했다

현대판타지 웹소설 — **검 대신 판을 짜는 현대한 협객**

> 게이트 붕괴로 죽은 E급 헌터가 10년 전으로 회귀해, 던전에는 들어가지 않고
> 헌터 협회 심사관이 되어 '판'을 짜는 자가 된다.
> 버려졌던 동료들을 이번엔 판 위에서 살린다.

- 장르: 현대판타지 × 회귀 × 협(俠)
- 타겟 플랫폼: 문피아
- 핵심 테마: 협을 중시하되 무협지가 아닌 — 현대의 협객 서사
- 집필 하네스: [awesome-novel-studio](https://github.com/MJbae/awesome-novel-studio)

## 디렉토리 구조

```
├── 게이트브로커_제안서.md      # 기획 제안서 (확정)
├── novel-config.md             # 프로젝트 설정 (큰 설계 후 생성)
├── design/                     # 설계 문서 (부트스트랩·캐릭터시트·플롯훅가이드)
├── episode/                    # 에피소드 본문
├── revision/                   # 윤문 작업 파일
└── _workspace/                 # 리서치·제안 산출물
```
